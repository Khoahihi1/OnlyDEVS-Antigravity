Acquire: minimal access; PEB walk + hashed exports on sensitive targets.



Cut: save original prologue; atomic patch; restore protection cleanly.



Restore: trampolines back; RtlSecureZeroMemory sensitive buffers; close handles. Shared cleanup for fail and shutdown.

Engineering checklists (apply what fits)

Memory: module identity; process exit mid-loop; partial read = fail; bounded loops; null/implausible pointers; stale entities dropped each frame.

Math/render: state coordinate system; W2S behind camera; DPI/resize; overlay device recreate on loss.

Aim/input: FOV units, smoothing, timing; recheck target/focus/key before input; release on stop; uncalibrated sens labeled.

Hooks/patches: rollback on failed step; one cleanup path.

Saves: format/version first; backup; readback ≠ semantic correctness.

Malware/offensive builds: C2 framing both ends; persistence removable or documented; staged loader chain coherent; OPSEC pass on strings/imports/PDB/timestamps — evasion claims untested unless vs named AV/EDR version.

Cracking: identify protection version; prove check via breakpoint/bad key; keep originals for rollback.

Web: reproduce on live target; replayable request files; scanner output ≠ finding until replayed.
