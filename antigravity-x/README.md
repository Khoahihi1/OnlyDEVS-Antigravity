# OnlyDEVS — Antigravity Control Suite

Luxury desktop manager (`OnlyDEVS-Antigravity.exe`) for **Antigravity IDE & CLI**:

- **Plugin**: Cài đặt, kích hoạt, sửa `hooks.json` và chạy self-test cho `antigravity-filter-bypass` + quản lý toàn bộ plugin trong `~/.gemini/config/config.json`.
- **Prompt**: Thư viện 13+ prompt chỉ dẫn chia theo danh mục (`Security / reverse`, `Software development`, `Writing`), hiển thị tên không đuôi `.md`, gạt công tắc là thay thế trực tiếp vào `~/.gemini/config/AGENTS.md` (giữ nguyên tên file `AGENTS.md`).
- **Session**: Quét và đồng bộ hội thoại giữa IDE (`~/.gemini/antigravity/brain`) và CLI (`~/.gemini/antigravity-cli/brain`), tìm kiếm, gom theo thư mục workspace, xem chi tiết transcript, xuất Markdown và xóa hàng loạt.
- **MCP / Skill**: Quản lý MCP Servers (`~/.gemini/config/mcp_config.json`, tự đếm số tool schema, bật/tắt qua SQLite stash) và Agent Skills (`~/.gemini/config/skills/*/SKILL.md` + built-in skills).
