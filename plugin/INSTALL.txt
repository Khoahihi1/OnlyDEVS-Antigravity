onlydevs-filter-bypass v1.3.1 — source package

Windows (recommended):
  1. Open OnlyDEVS-Antigravity.exe -> Plugins tab -> enable onlydevs-filter-bypass
  -- OR manual install --
  2. PowerShell inside plugin\: .\scripts\install.ps1
  3. Enable plugin: agy plugin enable onlydevs-filter-bypass
  4. Reload Window

Linux/macOS:
  chmod +x scripts/install.sh && ./scripts/install.sh

Test:
  python test_filter_bypass.py

Install target:
  %USERPROFILE%\.gemini\config\plugins\onlydevs-filter-bypass
